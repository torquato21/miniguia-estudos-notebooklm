# miniguia-estudos-notebooklm
## Objetivo
Esse guia tem como objetivo apresentar instruções, metodologias e técnicas para chegar ao sucesso de um possível negócio com mais qualidade e eficiência.
A abordagem foi criada para pessoas sem experiência nesse tipo de projeto. 
## Fontes
Fontes foram inseridas através da própria pesquisa rápida e pesquisa aprofundada da ferramenta. Prompt: Como criar um negócio de sucesso. 
Com o navegador anônimo e selecionando os resultados de maior relevância inseri fontes dos seguintes sites. Também foram realizadas pesquisas com a língua inglesa, utilizando a seguinte estrutura: "how to build a sucess business". 
- Youtube;
- Google acadêmico;
- Google.
